Description: Hover help text for Retry, Resubmit, Stop, and Terminate actions in the UI
Authors: [Kamil R](https://github.com/vidarlx)
Component: UI
Issues: 9541

Hover over Retry, Resubmit, Stop, or Terminate on a workflow to see a short caption that explains what the action does.
This helps you tell Retry from Resubmit and Stop from Terminate without leaving the page.
