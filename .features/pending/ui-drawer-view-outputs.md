Description: View a workflow's outputs from the workflows list drawer
Authors: [ljluestc](https://github.com/ljluestc)
Component: UI
Issues: 3530

Expanding a workflow's drawer on the workflows list page now shows a "View Outputs" button when the workflow has outputs.
It opens a popup listing the workflow's global outputs and its entrypoint's output parameters, artifacts, result and exit code.
This saves clicking through to the workflow details page just to check the outputs.
