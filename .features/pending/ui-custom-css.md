Description: Customize the UI with a CSS file
Authors: [Simon Domke](https://github.com/usimd)
Component: UI
Issues: 10825

Set `--css-file` on the Argo Server to add your own CSS to every page of the UI, including the login page, for example to show your own colors and logo.
The class names of the UI are not a stable API, so check your CSS when you upgrade.
